# 레포트 PDF 글꼴

Nanum Gothic Regular/Bold는 Google Fonts의 ofl/nanumgothic에서 가져왔다. SIL Open Font License 1.1과 원본 저작권 고지를 OFL.txt에 보존한다. 원본 커밋·URL·SHA-256은 source.json에 있다.

DejaVu Sans 2.37은 공식 dejavu-fonts/dejavu-fonts 릴리스에서 가져와 그리스 문자·수학 기호의 보조 글꼴로 사용한다. Bitstream Vera/DejaVu 라이선스와 저작권 고지는 DejaVu-LICENSE.txt, 원본 릴리스 URL·압축 파일/개별 파일 SHA-256은 dejavu-source.json에 보존한다.

글꼴 파일을 수정하지 않았다. 애플리케이션 배포 시 이 디렉터리의 글꼴·원본 기록·라이선스를 함께 포함한다. 런타임에 시스템 글꼴이나 외부 CDN을 조회하지 않는다.
