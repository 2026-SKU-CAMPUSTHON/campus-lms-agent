# 평가 질문과 참고 정답 — 검토자용 후보

실제 모델 결과가 아니다. 정답·근거는 사람 두 명의 검토 후 확정한다. 영상은 자동 자막 기반이다. 이 문서를 생성 프롬프트나 검색 자료로 사용하지 않는다.
