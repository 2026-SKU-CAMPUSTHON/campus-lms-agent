# LMS 에이전트 아이디어

> 현재 대화에서 사용자가 설명한 내용을 기록했다. 기능과 페르소나는 논의 중이며, 아래 미정 사항은 확정된 요구사항이 아니다.

## 프로젝트 배경

- 학교 공모전의 주제는 서경대학교 캠퍼스 문제 해결이다.
- 팀은 LMS 에이전트를 구상하고 있다.
- 초기 페르소나는 학생의 진취도를 확인하고 싶어 하는 열정적인 서경대학교 교수님이다.
- 두 아이디어를 합쳐 교수님 페르소나를 재정의했다. 현재 페르소나는 팀이 설정한 가설이며 실제 교수님 인터뷰로 검증하지 않았다.
- ‘진취도’의 구체적인 의미와 측정 방식은 아직 정하지 않았다.

## 1. 주차별 학습 범위 설정

교수님이 PPT와 사용할 페이지 범위를 입력한다. 해당 자료와 범위가 N주차 퀴즈의 기준이 된다.

- PPT의 학생 공개 여부는 교수님이 선택한다.
- PPT는 공개 또는 비공개로 설정할 수 있다.

## 2. AI 개념 퀴즈 생성 및 게시

AI가 지정된 PPT 범위를 기반으로 개념 확인용 퀴즈를 약 50문제 생성한다.

교수님은 다음 중 하나의 방식으로 게시할 문제를 선택한다.

- 생성된 문제를 직접 검토하고 원하는 문제만 선택한다.
- 전체 선택으로 생성된 문제를 모두 게시한다.

## 3. 학생의 자율적 퀴즈 참여

퀴즈 풀이는 필수가 아니다. 학생이 ‘Quiz 풀기’를 누르면 교수님이 사전에 선택하여 게시한 문제를 풀 수 있다.

## 4. 교수용 레포트

학생들의 퀴즈 풀이 결과를 바탕으로 레포트를 생성할 수 있다.

- 교수님은 레포트에서 확인할 주차를 선택한다.
- 전체 주차 선택도 가능하다.
- 선택한 주차에 대해 주차별 문제, 정답률, 참여율을 보여준다.

## 5. 학생용 레포트

학생도 자신의 퀴즈 결과를 레포트로 확인한다.

- 본인이 틀린 문제를 보여준다.
- 틀린 문제에 대한 풀이를 함께 제공한다.

## 첫 번째 아이디어: 퀴즈 서비스 흐름

1. 교수님이 PPT와 페이지 범위를 입력하고 주차를 설정한다.
2. PPT의 학생 공개 여부를 선택한다.
3. AI가 해당 범위의 개념 퀴즈를 약 50문제 생성한다.
4. 교수님이 일부 문제 또는 전체 문제를 선택하여 게시한다.
5. 학생이 자율적으로 퀴즈에 참여한다.
6. 교수님은 주차별 문제·정답률·참여율을 레포트로 확인한다.
7. 학생은 자신의 오답과 풀이를 레포트로 확인한다.

## 두 번째 아이디어: 주차별 Q&A 응답 에이전트

### 강의 자료 등록과 응답

교수님이 PPT와 해당 주차의 강의 녹음본 또는 동영상을 업로드한다. AI는 해당 주차의 자료를 기반으로 학생의 질문에 답한다.

### 추가 질문 및 교수님 Q&A 승격

- AI가 답을 찾지 못하면 대댓글로 학생에게 한 번 더 질문하여 질의를 명확히 한다.
- 추가 질문 후에도 학생의 질의를 이해하지 못하면 교수님이 직접 답하는 Q&A로 승격한다.
- 질문은 이해했지만 강의 자료에서 답을 찾을 수 없는 경우에도 교수님에게 넘긴다. 이 경우도 승격 대상이라는 점은 사용자가 확인했다.
- 질문이 모호하면 한 번 더 물어보고, 질문은 명확하지만 충분한 답변 근거를 확보하지 못하면 교수님에게 넘기는 구조로 정리했다. 검색 후 Jev 판단 결과와 추가 질문 횟수를 서버가 확인한다.

### Q&A 판단 기술 — Jev 도입 결정

- 강의·주차별 근거를 검색한 뒤 TypeSafe Jev가 질의 명확성과 검색 근거의 충분성을 각각 판단한다.
- Gemini는 답변과 추가 질문 문장을 생성한다.
- 서버가 Jev 판단 결과와 추가 질문 횟수를 확인하여 답변·추가 질문·교수님 승격으로 분기한다.
- 추가 질문은 스레드별 최대 1회로 제한한다. 학생이 추가 답변하면 다시 검색·판단하며, 여전히 해결하지 못하면 승격한다.
- Jev의 한국어 판단 기준과 임계값은 구현 시 검증한다. 현재는 설계 반영 단계다.

### 교수용 Q&A 레포트

교수님은 주차별 학생 질의 내역을 Q&A 레포트로 받는다. 구체적인 레포트 항목과 형식은 아직 정하지 않았다.

## 두 아이디어를 합친 교수님 페르소나

> **학생이 어디서 막히는지 파악하고, 필요한 순간에 직접 지도하고 싶은 서경대학교 교수님.**

이 페르소나는 팀이 설정한 가설이다. 실제 교수님 인터뷰로 검증한 결과가 아니다.

### 대상과 목표

- 학생의 이해와 자발적인 학습을 중요하게 생각하는 서경대학교 교수님이다.
- 학생들이 수업 내용을 이해하고, 스스로 복습하고 질문하도록 돕고 싶다.

### 겪는 어려움 — 검증할 가설

- 수업만으로는 학생들이 어떤 개념을 어려워하는지 파악하기 어렵다.
- 매주 복습 문제를 만들고 개별 질문에 답하는 데 시간이 든다.

### 필요한 지원

- 강의 자료를 활용한 개념 퀴즈 생성과 기본 질의응답 지원
- 학생들이 막히는 지점을 파악할 수 있는 주차별 레포트
- AI가 해결하지 못한 질문을 교수님에게 연결하는 기능

### 직접 개입할 순간

AI가 학생의 질문을 이해하지 못하거나 강의 자료에서 답을 찾지 못했을 때, 교수님이 직접 설명한다.

### 페르소나를 대표하는 가상 발언

> “학생들이 어디서 막히는지 알고 싶어요. 복습과 기본 질문은 바로 도움받게 하고, 제가 설명해야 할 질문에 집중하고 싶습니다.”

실제 교수님의 발언이 아니라 페르소나를 표현하기 위해 작성한 문장이다.

### 두 기능과 페르소나의 연결

- **퀴즈 레포트:** 어떤 개념에서 오답이 나오는지와 퀴즈 참여 현황을 확인한다.
- **Q&A 레포트:** 학생들이 무엇을 궁금해하는지 확인한다.
- **교수님 Q&A 승격:** AI가 해결하지 못한 질문을 교수님이 직접 지도할 수 있도록 연결한다.

두 아이디어는 학생의 학습 상태를 이해하고 필요한 지도를 제공한다는 목표로 연결된다. 기존의 ‘진취도 확인’보다 기능에서 직접 관찰할 수 있는 학습 참여와 이해의 어려움을 중심으로 페르소나를 재정의했다.

## 이해에 따른 해석 — 검증 전

- 교수용 레포트는 학생들의 퀴즈 참여 현황과 개념 이해도를 파악하는 데 도움을 줄 수 있다.
- 학생용 레포트는 자신이 놓친 개념을 복습하는 데 도움을 줄 수 있다.
- 퀴즈 참여율·정답률과 학생의 진취도 사이의 관계는 아직 정의하지 않았다. 이 지표만으로 진취도를 측정한다고 확정하지 않는다.

## 아직 정하지 않은 사항

- 실제 교수님 인터뷰는 진행하지 않고 현재 페르소나와 기능 정의를 기준으로 제작한다.
- 퀴즈 문항 유형과 학생에게 제시하는 문항 수·선정 방식
- 정답률·참여율의 집계 기준
- 레포트의 화면 형식 및 파일 다운로드 여부
- 기존 LMS와의 연동 방식
- Jev 판단 임계값·불확실/오류 처리 기준과 Q&A 레포트 세부 항목

## 다음 논의

현재 정리한 두 아이디어와 교수님 페르소나를 바탕으로 제작한다. 인터뷰는 진행하지 않는다. 구현 후보와 설계는 [추천 기술 아키텍처](architecture.md)에 정리했다.

## 구현한 교수 레포트 기준 (2026-10-21)

주차 다중 선택·전체 선택, 주차별 퀴즈 참여율·정답률, 문항별 문제·정답·풀이·출처, Q&A 상태 집계와 학생·AI·교수의 대화 내역을 제공한다. 현재 수강생 중 고유 제출 학생을 참여자로 세고 실제 제출 답안 수로 정답률을 계산한다. 전체 정답률은 분자·분모를 합산한다. Q&A는 전체 이력을 집계하고 목록만 페이지로 나눈다. 파일 다운로드는 아직 제공하지 않는다. 자세한 기준은 [레포트 명세](reports.md)에 기록했다.
