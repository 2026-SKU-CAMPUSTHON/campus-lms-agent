# 실제 모델 평가 — 2026-10-26

**퀴즈 30문항과 Q&A 30사례 × 2조건을 실제 API로 실행했다. Jev 미적용/적용의 후보 기대 분기 일치는 20/30 → 26/30, 퀴즈 무수정 사용은 AI 잠정 채점 27/30이다.** 사람 독립 검토와 원영상 확인 전 결과이며 검증된 정확도·교수 승인으로 해석하지 않는다. 자동으로 생성·게시 가능한 품질을 보증하지 않는다.

PDF는 `ch13_텍스트 마이닝.pdf` 18–23쪽·44–59쪽, 영상은 [공학수학 강의](https://www.youtube.com/watch?v=XwsPTAnFRsk)의 기존 한국어 자동 자막 1200–1690초를 사용했다. 개발 범위는 PDF 5–11쪽·영상 732–832초다. 자료 해시는 [manifest](../../evaluation/v1/source-manifest.json), 모든 세트/자료 해시와 모델 설정은 로컬 run의 `metadata.json`에 기록했다. 원영상 소리·판서는 대조하지 않았다. 경계 자막은 시각만 자르고 전체 cue 텍스트를 보존하므로 단어 단위의 엄밀한 경계 격리는 아니다.

두 조건은 같은 초기 검색 결과를 사용했다(30/30쌍의 passage 해시 일치). `direct_answer`는 Jev 판단과 자동 보완 질문을 우회하지만 검색 결과 없음·유효 출처 없음의 기존 승격은 유지한다. 고정 우회값 1은 모델이 측정한 확률이 아니다. `jev_gate`는 실제 Jev 판단과 보완 1회·승격 정책을 사용한다. 보완이 요청될 때만 미리 정한 학생 응답을 한 번 보냈다. 조건 순서는 사례별 교차했으며 개발 결과 이후 설정을 바꾸거나 좋은 출력으로 교체하지 않았다.

실행기 원문 해시와 앱 커밋을 함께 기록한 이유는 실행기가 이 run 당시 미커밋 신규 파일이었기 때문이다. 이 PR에 보존된 실행기 바이트를 위 해시로 대조할 수 있다. 운영 서버·실제 학생 DB는 변경하지 않았으며 MySQL 부하·실서비스 지연 측정이 아니다.

분기 일치의 차이는 **+20.0%p**다. 같은 사례 쌍에서 양쪽 일치 19개, Jev만 일치 7개, 미적용만 일치 1개, 양쪽 불일치 3개였다. 보완 후 답변을 기대한 5개는 Jev 2/5에서 해당 전체 경로와 일치했고, 보완 후 승격을 기대한 5개는 5/5 일치했다. 후자를 초기부터 답할 수 있는 질문의 성공으로 세지 않았다.

내용 점수 100%는 **실제로 답변한 12개만의 잠정 값**이다. 승격한 18개까지 정답이라는 뜻이 아니다. 답변 없음의 정답·근거·출처 점수는 `N/A`로 두었다. 직접 조건의 모호한 답변 일부는 대상을 가정한다고 명시했으므로 부분 정확 1점을 주되 근거 없는 단정으로 중복 집계하지 않았다. 따라서 이 결과로 환각 감소를 입증했다고 주장할 수 없다.

지연은 초기 요청과 보완 응답 후 처리 시간의 합이며 학생 입력 준비·교수 답변 대기는 제외했다. 생성 생략·승격 비중과 단일 실행의 네트워크 변동이 섞이므로 Jev가 더 빠르다고 일반화하지 않는다. 이 비교는 **Jev 포함 보완·분기 정책 전체**에 대한 비교이며 Jev 모델만의 순수 효과가 아니다.

수정 필요 3개는 G1-03, G1-07, G3-06이다. 처음 반환된 문항과 보기를 그대로 채점했으며 이 평가에서 교수 수정·게시를 수행하거나 수정 시간을 측정하지 않았다.

- **G1-03:** min_df/max_df 설명의 문서 빈도 단위가 모호하다. min_df=3은 최소 3개 문서, max_df=0.9는 문서 비율 90%를 기준으로 한다. 단순 단어 출현 횟수로 읽히는 보기·풀이를 수정해야 한다. [TfidfVectorizer 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html)
- **G1-07:** `best_params_`, `best_score_`, `best_estimator_`의 끝 `_`가 빠져 올바른 코드 속성이 없는 보기였다. PDF p.22 이미지에는 밑줄이 있지만 추출 텍스트에 손실됐다. 정답·풀이·보기 각 0점이다. [GridSearchCV 공식 문서](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GridSearchCV.html)
- **G3-06:** 항을 늘리면 y=x에 가까워진다는 설명에 “정해진 구간 안” 조건이 필요하다. 자막은 밖에서 주기적으로 반복함도 설명한다. 핵심 방향은 인정하되 범위가 불명확한 보기·풀이 0점으로 두었다. 원영상 확인 전 잠정 판정이다.

정답 위치는 A 19개·B 9개·C 0개·D 2개이며 PDF_MODEL 10개는 전부 A였다. 문항별 정확성과 별개인 배치 편향으로 기록했다. 게시 전 보기 순서와 정답 매핑을 함께 검토해야 한다. G2-04/G2-10은 일부 개념이 겹치지만 후자가 모델 생성 단계를 포함하므로 “표현만 바꾼 중복”으로 세지 않았다.
