# 채점 기준

`1.0.0-candidate` · 미실행·미검토는 빈칸, 실제 실패는 0 또는 실패, 적용 불가는 `N/A`다. 분모가 0인 지표는 표시하지 않는다. 모든 판정은 원문을 확인한 사람이 입력한다.

## 퀴즈

요청 30슬롯을 모두 기록한다. 처음 반환된 순서로 채점하고 부족한 문항은 실패/누락으로 남긴다. 좋은 문항으로 교체하지 않는다. 수정 전 품질과 교수 수정 후 품질은 별도로 기록한다.

| 항목 | 1점 | 0점 |
| --- | --- | --- |
| 정답 정확성 | 원문과 일치 | 오류·판단 불가 |
| 풀이 정확성 | 정답 이유를 정확히 설명 | 오류·핵심 누락·근거 없음 |
| 보기 유효성 | 단일 정답, 명확한 표현 | 복수 정답·정답 없음·모호 |
| 범위 준수 | 선택 범위에서 뒷받침 가능 | 범위 밖 지식 필요 |
| 중복 여부 | 중복이면 1 | 아니면 0 |

중복은 같은 배치에서 표현만 바꿔 같은 개념·추론·정답을 반복한 경우다. 첫 문항 뒤의 중복 문항에 표시한다. 출처가 실제 주장을 뒷받침하는지도 확인한다. 처분은 `그대로 사용` / `수정 후 사용` / `폐기`다. **무수정 합격은 앞 네 항목이 모두 1, 중복이 0, 처분이 그대로 사용일 때만 1이다.**

- 생성 완료율: 실제 생성 문항 / 요청 30. 파싱 실패·누락·API 오류를 별도 기록한다.
- 전체 무수정 사용률: 합격 문항 / 요청 30. 모든 슬롯 처리 후 최종값을 제시한다.
- 검토 내 무수정 사용률: 합격 문항 / 검토 완료 문항. 진행 중 수치와 구분한다.
- 항목별 오류율·중복률: 해당 오류 문항 / 해당 항목 검토 문항. 분자·분모를 함께 제시한다.
- 수정 시간: 출력 검토 시작부터 게시 가능한 상태까지의 초. 생성 대기와 구분한다.

## Q&A

평가 단위는 초기 질문부터 최대 한 번의 보완 후까지인 대화 1개다. 두 응답을 표본 두 개로 세지 않는다. 기대 경로는 `answer`, `handoff`, `clarify>answer`, `clarify>handoff`다. 반복 보완 등 잘못된 경로도 실제 그대로 기록한다.

| 항목 | 판정 |
| --- | --- |
| 경로 일치 0/1 | 전체 경로 일치 1; API 실패는 0; 미실행 빈칸 |
| 정답 0/1/2 | 2 핵심 정확·질문 충족 / 1 부분 정확·일부 누락 / 0 오류·무관. 답변 없음은 N/A |
| 근거 충실성 0/1 | 검증 가능한 핵심 주장이 허용 근거에 모두 부합하면 1; 답변 없음 N/A |
| 출처 정확성 0/1 | 페이지·시간이 주장을 뒷받침하면 1; 링크 존재만으로 통과하지 않음; 답변 없음 N/A |
| 근거 없는 자동 답변 0/1 | 답변 시점에 정보·강의 근거가 부족한데 단정하면 1; 적절한 보완 후 답변은 0 |
| 검색 적중 0/1/N/A | 답이 있는 사례의 검색 결과에 충분한 근거가 있으면 1, 놓치면 0; 본래 답 없는 사례 N/A |
| 보완 횟수 | 요청한 추가 질문 수. 1회 초과는 제한 위반 |

문장 완전 일치는 요구하지 않는다. 의미·핵심이 같으면 인정한다. 수식·기호는 PDF나 원영상으로 확인한다. 잘못된 자동 자막과 일치한다는 이유로 틀린 수학을 정답 처리하지 않는다.

- 경로 정확도: 일치 대화 / 시도한 대화. API 실패 포함. 전체 30개 및 범주별 10개를 조건별로 제시한다.
- 충분한 질문의 답변 성공률: 초기 답변 가능 10개 중 정답 2·근거 1·출처 1인 답변 / 10. 실패·승격은 성공이 아니다.
- 불필요한 승격률: 초기 답변 가능 10개 중 승격 / 10. 보완 후 답변 가능해진 5개는 별도 제시한다.
- 내용 정답률: 정답 2인 대화 / 실제 답변을 사람이 검토한 대화. 답변 커버리지도 함께 제시한다.
- 근거 없는 자동 답변률: 모호·근거 부족 20개 중 해당 오류 대화 / 20. 모두 시도하기 전에는 부분 결과라고 표시한다.
- 보완 제한 위반: 보완 2회 이상 대화 / 시도한 대화.
- 지연 시간: 초기·보완 후 요청 처리 시간 합. 학생 입력 준비와 교수 답변 대기는 제외한다. 평균·중앙값·최대와 성공/실패 수를 함께 기록한다.
- 비용: 해당 대화의 생성·판단 호출 합. 통화·사용량·가격 기준일을 기록한다. 확인 불가는 빈칸이다.

같은 사례의 두 조건을 짝지어 비교한다. 표본이 작아 큰 성능 개선·통계적 유의성을 단정하지 않는다. 검색, 전사, Jev 판단, 생성, 상태/권한, API 오류를 구분한다. 전체 자료에는 답이 있으나 검색에 실패한 경우 전체 시스템 실패이며 Jev 단독 오류라고 단정하지 않는다.

## 기능과 시간

기능 검사 기대 결과를 모두 만족해야 통과다. 실패에는 재현 단계·역할·코드 버전·증거를 남긴다. 타인 기록 노출, 제출 전 정답 유출, 오채점, 기록 소실은 시연 전 해결할 중대 결함이다. 참여율은 고유 참여 학생 / 현재 수강 학생, 정답률은 정답 합 / 제출 답안 합으로 대조한다. 빈 분모와 미응시를 실제 0점과 구분한다.

시간 실험은 내부 팀원 4명의 파일럿이다. 비슷한 난이도·분량의 서로 다른 자료 블록 A/B를 고정한다. P1은 A 직접 작성 후 B AI, P2는 B AI 후 A 직접 작성, P3은 B 직접 작성 후 A AI, P4는 A AI 후 B 직접 작성한다. 자료 배정과 조건 순서를 모두 교차한다. 두 조건 모두 5문항을 같은 기준으로 승인받는다. 시작은 자료를 열고 작업 시작, 종료는 독립 검토자의 사용 가능 승인이다. 생성 대기·검토·수정은 포함하고 휴식은 별도 기록한다. 두 조건 모두 품질 승인된 기록만 비교한다.

`시간 절감률 = (직접 작성 초 − AI 사용 초) / 직접 작성 초`

직접 시간이 0이면 계산하지 않는다. 음수도 유지한다. 개인별 결과·유효 참가자 수를 공개하고 실제 교수 실험이나 학습 효과로 표현하지 않는다. 순서 교차가 모든 학습 효과를 제거한다고 주장하지 않는다.
