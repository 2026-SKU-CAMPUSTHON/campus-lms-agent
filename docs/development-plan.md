## 2026-10-21 진행

퀴즈 첫 기능은 PR #7에서 검토 중이다. 이어지는 Q&A 브랜치 `feat/d-4-qa-jev`는 해당 브랜치를 기반으로 한다. Q&A 화면·단어 검색·Jev SDK 어댑터·추가 질문 1회·교수 답변과 오류 재시도를 구현했다. Codex가 실제 강의 PDF의 근거로 답변과 추가 질문 문장을 생성하는 것은 확인했다.

다음 통합 순서는 TypeSafe 키 설정과 실제 한국어 Jev 판단 검증, 퀴즈/Q&A PR 검토, Supabase 인증·저장 이관, 주차별 레포트, 녹음·영상 전사, 최종 배포다. 자동 검사에서 Jev 응답을 주입한 결과와 실제 Jev 검증은 구분한다.

## Claude 생성·실제 Jev 연결 후속 작업

사용자 요청으로 기본 생성을 Claude API로 바꾸고 Jev 판단은 유지했다. 브랜치 `feat/cd-4-claude-api`는 PR #8을 기반으로 한다. 실제 강의 PDF로 Claude 퀴즈 3문항과 실제 Jev·Claude Q&A의 답변·보완 질문 1회·교수 승격·교수 답변을 확인했다. 다음 작업은 PR 순서에 따른 검토, 한국어 판단 평가 확장, Supabase 이관·레포트·전사·배포다.

## 교수 레포트 후속 작업

사용자 요청으로 feat/ab-6-weekly-reports에서 API 0.4.0-reports.1의 교수 주차별 퀴즈·Q&A 레포트와 화면을 구현했다(PR #9 기반). 실제 현재 수강생을 분모로 사용하며 전체 정답률은 합산 비율이다. 이슈 #6 중 레포트 범위만 진행하며 Supabase·배포·리허설은 계속 남아 있다. 다음 담당은 선행 PR 순서대로 검토하고 수강 이력 스냅샷이 필요한지 실제 강의 운영 요구를 확인한다.

## 녹음·동영상 자동 전사 후속

사용자 요청으로 feat/bcd-3-media-transcription에서 API 0.5.0-media.1의 로컬 전사·시간 출처·공개 권한·재시도를 구현했다(PR #10 기반). B/C/D 및 공용 타입·계약에 영향을 주며 이슈 #3에 인계한다. 실제 음성 샘플의 모델 호출과 자동 검사의 전사·판단·생성 대역을 구분한다. 실제 강의 길이·잡음 환경의 ASR 품질과 처리 시간 평가는 남아 있다.

## YouTube 공개 영상 수집 후속

후속 사용자 요청으로 feat/bc-3-youtube-quiz에서 API 0.7.0-youtube-quiz.1의 YouTube 퀴즈 생성·시간 출처·교수 검토/선택 게시·학생 오답·레포트를 연결했다(PR #12 기반). B/C와 공용 Source/레포트에 미치는 범위를 이슈 #3에 공유했다. 실제 강의·Claude의 생성과 임시 DB의 게시/채점 검증, 자동 검사 대역을 구분한다. 실제 로컬 초안은 교수 검토용으로 남기며 자동 게시하지 않는다.

사용자 요청으로 feat/bcd-3-youtube-import에서 API 0.6.0-youtube.1의 자막 우선 수집·음성 ASR 대체, 링크/시작·끝 시간 입력, 같은 주차 Q&A 시간 출처·원본 이동과 공개 권한을 구현했다(PR #11 기반). 이슈 #3에서 B/C/D 영향과 담당을 공유했다. 실제 제공 영상의 자막→Jev→Claude→레포트와 음성 다운로드/ASR 구성요소를 별도로 검증한다. 원본 공개 상태·접근 제한은 우회하지 않는다. 다음 담당은 선행 PR 검토와 시연 질문/자동 자막 품질 확인·Supabase 통합을 이어간다.


## 교수 초안 수정 후속
