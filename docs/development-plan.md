## 2026-10-21 진행

퀴즈 첫 기능은 PR #7에서 검토 중이다. 이어지는 Q&A 브랜치 `feat/d-4-qa-jev`는 해당 브랜치를 기반으로 한다. Q&A 화면·단어 검색·Jev SDK 어댑터·추가 질문 1회·교수 답변과 오류 재시도를 구현했다. Codex가 실제 강의 PDF의 근거로 답변과 추가 질문 문장을 생성하는 것은 확인했다.

다음 통합 순서는 TypeSafe 키 설정과 실제 한국어 Jev 판단 검증, 퀴즈/Q&A PR 검토, Supabase 인증·저장 이관, 주차별 레포트, 녹음·영상 전사, 최종 배포다. 자동 검사에서 Jev 응답을 주입한 결과와 실제 Jev 검증은 구분한다.
