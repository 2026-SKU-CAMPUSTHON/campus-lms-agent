# 교수 주차별 레포트

API `0.4.0-reports.1`. 같은 강의의 교수만 조회한다. 학생은 탭을 볼 수 없고 API도 403으로 차단한다. 통계는 저장된 자료를 SQL과 코드로 계산하며 Claude·Jev를 다시 호출하지 않는다.

## 화면과 조회

교수 체험으로 로그인한 뒤 **수업 레포트** 탭을 선택한다. 처음에는 강의의 전체 주차를 조회하며 한 개 또는 여러 주차를 선택할 수 있다. 아무 주차도 선택하지 않으면 조회하지 않는다. 새로고침은 현재 저장된 결과로 다시 집계한다.

주차 비교표에서 게시 퀴즈·문항 수, 참여 학생, 참여율, 정답률, 질문 수를 본다. 문항별 결과를 펼치면 문제·정답률·분자/분모와 정답·풀이·출처를 확인한다. Q&A는 학생 이름·주차·질문·상태·보완 질문 횟수를 보여주며 대화를 펼쳐 AI와 교수의 답변·출처를 확인한다. 응답 오류도 표시한다.

## 퀴즈 계산 기준

- **집계 대상:** 조회 시점의 강의 membership 중 role=student인 수강생. 교수와 다른 강의 학생은 제외한다. 현재 수강생의 제출만 집계한다.
- **참여 학생:** 선택한 주차의 게시 퀴즈를 하나 이상 제출한 고유 학생 수. 같은 학생이 여러 퀴즈나 여러 주차에 제출해도 전체 참여 학생은 한 명으로 센다.
- **참여율:** 참여 학생 수 / 현재 수강 학생 수. 초안이나 퀴즈 열람은 참여가 아니다. 게시 퀴즈가 없거나 수강생이 0명이면 null(화면에서는 —)이다. 게시 퀴즈가 있지만 아무도 제출하지 않으면 0%다.
- **정답률:** 정답 수 / 실제 제출한 답안 수. 각 퀴즈의 완전한 제출만 있으며 퀴즈당 학생 제출은 1회다. 미제출을 오답으로 세지 않는다. 제출 답안이 0개이면 null(—), 모두 틀리면 0%다.
- **문항별 정답률:** 해당 문항의 정답 수 / 해당 문항을 포함한 퀴즈 제출 수.
- **전체 선택:** 정답 수와 답안 수를 합산한다. 주차별 정답률을 단순 평균하지 않는다. 게시 문항 수는 게시 퀴즈에 포함된 문항 수의 합이다.

예를 들어 1주차 3/5 정답, 2주차 0/1 정답이면 전체는 **3/6=50%**다. 주차 비율 60%와 0%의 평균인 30%를 사용하지 않는다.

현재는 수강 이력 스냅샷이 없어 수강생 구성이 바뀌면 과거 주차의 분모와 집계 대상도 바뀐다. 게시 당시 또는 주차 마감 당시 수강생 기준이 필요하면 enrollment 이력·스냅샷을 추가해야 한다.

## Q&A 계산과 페이지

선택한 주차의 저장된 질문 전체를 집계하며 수강생 탈퇴 후의 이력도 포함한다. 학생의 보완 답변은 새 질문이 아니라 기존 스레드의 메시지다. open / awaiting_student / awaiting_professor / resolved는 조회 시점의 현재 상태다. 응답 오류 수는 상태 집계와 중복될 수 있고 오류를 교수 승격으로 바꾸지 않는다.

대화 목록은 기본 25개, 최대 100개씩 페이지로 조회한다. 목록이 여러 페이지여도 주차별·전체 집계는 해당 주차의 질문 전체를 포함한다. 대화에는 교수용 Q&A 공개 형식을 사용하고 내부 판단 기록·학생 UUID·API 설정을 넣지 않는다.

## API

- `GET /api/courses/{course_id}/reports/quizzes?week_ids=uuid,uuid`
- `GET /api/courses/{course_id}/reports/qa?week_ids=uuid,uuid&page=1&page_size=25`

week_ids 생략은 전체 주차다. 빈 값·잘못된 UUID·범위 밖 페이지 인수는 422, 소속 강의가 다른 주차는 404다. 주차 중복은 제거하며 주차 번호순으로 반환한다. 두 API는 각각 generated_at을 반환하므로 조회 시점을 구분할 수 있다. 보고서 파일 다운로드와 AI 서술형 요약은 이번 범위에 포함하지 않는다.
