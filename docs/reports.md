# 교수 주차별 레포트

현재 API `0.10.0-student-report.1` (화면 레포트 최초 계약은 `0.4.0-reports.1`). 같은 강의의 교수만 조회한다. 학생은 탭을 볼 수 없고 API도 403으로 차단한다. 통계는 저장된 자료를 SQL과 코드로 계산하며 Claude·Jev를 다시 호출하지 않는다.

## 화면과 조회

교수 체험으로 로그인한 뒤 **수업 레포트** 탭을 선택한다. 처음에는 강의의 전체 주차를 조회하며 한 개 또는 여러 주차를 선택할 수 있다. 아무 주차도 선택하지 않으면 조회하지 않는다. 새로고침은 현재 저장된 결과로 다시 집계한다.

주차 비교표에서 게시 퀴즈·문항 수, 참여 학생, 참여율, 정답률, 질문 수를 본다. 문항별 결과를 펼치면 문제·정답률·분자/분모와 정답·풀이·출처를 확인한다. Q&A는 학생 이름·주차·질문·상태·보완 질문 횟수를 보여주며 대화를 펼쳐 AI와 교수의 답변·출처를 확인한다. 응답 오류도 표시한다.

## 퀴즈 계산 기준

- **집계 대상:** 조회 시점의 강의 membership 중 role=student인 수강생. 교수와 다른 강의 학생은 제외한다. 현재 수강생의 제출만 집계한다.
- **참여 학생:** 선택한 주차의 게시 퀴즈를 하나 이상 제출한 고유 학생 수. 같은 학생이 여러 퀴즈나 여러 주차에 제출해도 전체 참여 학생은 한 명으로 센다.
- **참여율:** 참여 학생 수 / 현재 수강 학생 수. 초안이나 퀴즈 열람은 참여가 아니다. 게시 퀴즈가 없거나 수강생이 0명이면 null(화면에서는 —)이다. 게시 퀴즈가 있지만 아무도 제출하지 않으면 0%다.
- **정답률:** 정답 수 / 실제 제출한 답안 수. 각 퀴즈의 완전한 제출만 있으며 퀴즈당 학생 제출은 1회다. 미제출을 오답으로 세지 않는다. 제출 답안이 0개이면 null(—), 모두 틀리면 0%다.
- **문항별 정답률:** 해당 문항의 정답 수 / 해당 문항을 포함한 퀴즈 제출 수.
- **전체 선택:** 정답 수와 답안 수를 합산한다. 주차별 정답률을 단순 평균하지 않는다. 게시 문항 수는 게시 퀴즈에 포함된 문항 수의 합이다.

예를 들어 1주차 3/5 정답, 2주차 0/1 정답이면 전체는 **3/6=50%**다. 주차 비율 60%와 0%의 평균인 30%를 사용하지 않는다.

현재는 수강 이력 스냅샷이 없어 수강생 구성이 바뀌면 과거 주차의 분모와 집계 대상도 바뀐다. 게시 당시 또는 주차 마감 당시 수강생 기준이 필요하면 enrollment 이력·스냅샷을 추가해야 한다.

## Q&A 계산과 페이지

선택한 주차의 저장된 질문 전체를 집계하며 수강생 탈퇴 후의 이력도 포함한다. 학생의 보완 답변은 새 질문이 아니라 기존 스레드의 메시지다. open / awaiting_student / awaiting_professor / resolved는 조회 시점의 현재 상태다. 응답 오류 수는 상태 집계와 중복될 수 있고 오류를 교수 승격으로 바꾸지 않는다.

대화 목록은 기본 25개, 최대 100개씩 페이지로 조회한다. 목록이 여러 페이지여도 주차별·전체 집계는 해당 주차의 질문 전체를 포함한다. 대화에는 교수용 Q&A 공개 형식을 사용하고 내부 판단 기록·학생 UUID·API 설정을 넣지 않는다.

## API

- `GET /api/courses/{course_id}/reports/quizzes?week_ids=uuid,uuid`
- `GET /api/courses/{course_id}/reports/qa?week_ids=uuid,uuid&page=1&page_size=25`

week_ids 생략은 전체 주차다. 빈 값·잘못된 UUID·범위 밖 페이지 인수는 422, 소속 강의가 다른 주차는 404다. 주차 중복은 제거하며 주차 번호순으로 반환한다. 두 API는 각각 generated_at을 반환하므로 조회 시점을 구분할 수 있다. 교수 PDF 다운로드는 아래 명세를 따른다. AI 서술형 요약은 포함하지 않는다.


## PDF 다운로드

**수업 레포트**에서 한 개 또는 여러 주차를 고른 뒤 **PDF 다운로드**를 누른다. 전체 주차 선택도 가능하며 선택이 없으면 다운로드할 수 없다. 생성 중에는 주차 선택과 중복 다운로드를 잠근다. 오류는 화면에 표시하고 다시 다운로드할 수 있다. 조회 화면과 같은 SQL 계산 기준을 쓰며 PDF 요청 시점의 현재 결과를 새로 집계한다. 먼저 조회한 화면 이후 제출이 늘면 파일 수치도 달라질 수 있다.

`GET /api/courses/{course_id}/reports/pdf?week_ids=uuid,uuid`는 같은 강의의 교수만 접근한다. week_ids 생략은 전체 주차다. 잘못된 인수는 422, 다른 강의 주차는 404, 학생·다른 강의 교수는 403이다. 성공은 application/pdf, Content-Disposition attachment(ASCII filename 및 UTF-8 filename*), Cache-Control no-store다. 파일은 서버 디스크에 남기지 않고 메모리에서 반환한다.

PDF는 강의명·선택 주차·생성 시각(KST), 전체 요약, 주차별 비교표, 게시된 문항별 문제·보기·정답·풀이·정답률/분자/분모·페이지/영상 시간 출처, Q&A 학생 이름·현재 상태·추가 질문 횟수·승격 사유·오류·학생/AI/교수 메시지·출처를 포함한다. Q&A는 화면의 현재 페이지와 관계없이 선택 주차의 전체 대화를 포함한다. 내부 Jev 판단/확률, 학생 UUID, 모델 설정/키, 원본 파일 경로·전체 전사·원본 미디어 URL을 별도 필드로 추가하지 않는다. 텍스트 속 HTML/이미지 태그는 일반 텍스트로 출력하고 외부 자료를 로드하지 않는다.

하나의 SQLite 트랜잭션에서 퀴즈/Q&A 스냅샷을 만들고 공통 생성 시각을 기록한다. 이후 Python ReportLab에 JSON을 stdin으로 전달하고 PDF bytes를 stdout으로 받는다. 셸을 실행하지 않으며 API 키/토큰 환경 변수를 자식 프로세스에서 제거한다. Worker 큐 draft-1과 별개인 로컬 렌더링 CLI다. Claude·Jev 호출과 과금은 추가되지 않는다.

`worker/requirements.txt`의 reportlab==4.4.10과 pypdf를 설치하고 기존 PYTHON_BIN을 같은 환경으로 지정한다. CI도 같은 의존성을 설치한다. Nanum Gothic과 수학/그리스 문자용 DejaVu Sans를 파일 안에 포함한다. 배포 시 worker/report_pdf.py와 worker/fonts 전체를 함께 제공해야 한다. [글꼴 원본·라이선스](../worker/fonts/README.md)를 보존한다. 두 글꼴에도 없는 문자는 누락하지 않고 [U+코드]로 표시하며 파일 끝에 안내한다. 한글 줄바꿈·긴 문장·표 반복 머리글·페이지 번호를 지원한다.

명시적 한도는 요청당 게시 문항 2,000개·Q&A 1,000개·입력 JSON 16MiB·결과 PDF 32MiB·생성 30초이며 앱당 동시 생성은 2개다. 초과 시 잘라내지 않고 422 REPORT_TOO_LARGE 또는 503 REPORT_TIMEOUT, 동시 요청 초과는 429 REPORT_BUSY로 주차 분할/재시도를 안내한다. Python/의존성/글꼴 문제는 503 REPORT_PDF_UNAVAILABLE이며 오류 JSON을 정상 PDF로 저장하지 않는다. 큰 학기 전체 자료의 백그라운드 내보내기는 후속 작업이다.

공식 구현 참고: [ReportLab 한글/TrueType 글꼴](https://docs.reportlab.com/reportlab/userguide/ch3_fonts/), [문단/CJK 줄바꿈](https://docs.reportlab.com/reportlab/userguide/ch6_paragraphs/), [페이지 레이아웃](https://docs.reportlab.com/reportlab/userguide/ch5_platypus/).


## 학생 개인 오답 레포트

학생 계정의 **오답 레포트** 탭에서 복습할 강의 주차를 하나/여러 개/전체 선택하고 **오답 PDF 다운로드**를 누른다. 강의에 등록한 주차 기준이며 달력의 주 번호가 아니다. 화면은 본인의 제출 퀴즈 수·풀이 문항 수·오답 수·정답률과 주차별 기록을 보여준다. 다운로드 중에는 중복 클릭/주차 선택을 막고 오류 안내 후 다시 받을 수 있다. 선택이 없으면 조회/다운로드하지 않는다.

- `GET /api/courses/{course_id}/reports/wrong-answers?week_ids=uuid,uuid`: 본인의 JSON 요약과 주차별 제출/오답.
- `GET /api/courses/{course_id}/reports/wrong-answers/pdf?week_ids=uuid,uuid`: 같은 본인 제출 범위의 PDF attachment.

week_ids 생략은 강의 전체 주차다. 세션 사용자와 해당 강의의 student membership을 서버가 확인한다. 교수·비수강생은 403, 비로그인은 401이다. 다른 강의의 주차는 404, 잘못된/빈 필터 및 user_id/attempt_id/quiz_id 등 임의 필드는 422다. 클라이언트가 학생 ID를 지정하지 않는다. JSON과 PDF 모두 동일한 서버 범위를 사용하며 화면 숨김으로 권한을 대체하지 않는다.

저장된 attempts를 현재 사용자·강의·선택 주차로 SQL에서 제한한다. 본인의 제출 횟수/총 풀이/정답/오답과 전체 정답률(정답 수/풀이 수)을 계산하며 분모 0은 null이다. 제출하지 않은 퀴즈는 정답률/오답의 분모에 포함하지 않는다. 선택된 주차별로 본인의 제출 기록을 모두 모으고, 같은 강의의 다른 학생/다른 강의/미제출·맞힌 문항의 문제·정답/교수 집계·Q&A는 응답과 PDF에 넣지 않는다.

오답은 제출 당시 저장된 wrong_questions를 사용한다. 문제·보기·내 선택·정답·풀이·페이지/영상 시간 출처를 그대로 보존하고 게시 퀴즈의 문항 번호와 주차별 퀴즈 번호를 붙인다. 현재 자료로 정답이나 풀이를 재생성하지 않는다. PDF는 원본 미디어 URL/재생 링크를 제공하지 않고 비공개 시간 출처에는 원본 비공개를 표시한다. 기존 실제 원본 접근 권한은 계속 서버에서 검사한다.

한 건도 제출하지 않았으면 ‘아직 제출한 퀴즈가 없습니다’로 표시하고 정답/오답 문항을 넣지 않는다. 제출했으나 오답이 0개면 ‘모두 맞혔습니다. 오답이 없습니다’로 구분한다. 미응시를 모두 정답으로 처리하지 않는다. PDF는 학생 이름·강의명·선택 주차·생성 시각(KST), 요약/주차별 표, 본인의 오답과 선택 답/정답 표시·풀이/출처를 담는다.

제출 1,000건 또는 오답 2,000개를 넘으면 422 REPORT_TOO_LARGE로 주차 분할을 요청한다. 같은 PDF 렌더러의 JSON 16MiB·PDF 32MiB·30초 및 교수/학생이 공유하는 동시 2개 한도를 사용한다. 넘친 내용을 조용히 생략하지 않는다. no-store·ASCII/UTF-8 attachment 파일명·키 제거 stdin/stdout·한글/수학 글꼴·환경 오류 처리도 교수 PDF와 같다. API/DB 저장 스키마나 Worker 큐는 바꾸지 않으며 Claude/Jev 호출은 없다.

[합성 계약 샘플](contracts/examples/student-wrong-report.json)과 실제 검증 범위는 [검증 기록](verification.md)을 따른다. 샘플은 실제 학생이나 강의 내용이 아니다.
