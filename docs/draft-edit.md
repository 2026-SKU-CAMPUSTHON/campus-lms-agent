# 교수의 퀴즈 초안 수정

교수 계정의 개념 퀴즈에서 미게시 초안의 **문제 수정**을 누른다. 문제, 보기 네 개, 정답 하나, 풀이를 바꾸고 **수정 내용 저장**을 누른다. 저장한 내용을 검토한 다음 필요한 문항을 선택해 게시한다. 문서와 YouTube 초안에 같은 기능을 제공한다. 수동 수정은 생성 모델이나 Jev를 호출하지 않는다.

문항·보기 ID와 보기 순서, 페이지·영상 시간 출처는 유지한다. 보기를 추가하거나 삭제할 수 없다. 수정한 설명이 기존 출처와 맞는지는 교수가 확인해야 한다. 문제는 2,000자, 각 보기는 1,000자, 풀이는 4,000자 이내이며 빈 값과 중복 보기는 거부한다. 입력은 일반 텍스트로 표시한다.

편집 중에는 다른 문항 편집, 선택 변경, 게시, 탭·강의·주차 이동과 로그아웃을 막는다. **수정 취소**는 저장하지 않은 입력을 버린다. 새로고침·창 닫기는 브라우저의 기본 이탈 확인을 사용한다. 자동 저장은 없다. 저장 오류가 나면 입력을 유지한다.

## 저장·게시 계약

API 계약은 `0.8.0-draft-edit.1`이다. `QuizDraft.version`은 1부터 시작하며 한 문항을 저장할 때마다 증가한다. 버전이 없는 기존 저장 초안은 조회 시 1로 해석하므로 별도 DB 마이그레이션은 필요 없다.

`PATCH /api/quiz-drafts/{draft_id}/questions/{question_id}`는 교수 세션, 해당 강의 권한, `Idempotency-Key`를 요구한다. 요청은 `expected_version`, `prompt`, `options`, `correct_option_id`, `explanation`이며 [합성 샘플](contracts/examples/edit-draft-question.json)을 따른다. 서버는 기존 네 보기 ID만 허용하고 수정 후 전체 QuizDraft를 반환한다.

게시 요청도 `expected_version`이 필수다. 버전을 누락한 이전 클라이언트는 422를 받으므로 프런트엔드·검증 스크립트를 함께 갱신했다. 서버는 트랜잭션 안에서 최신 초안을 읽고 버전을 확인한 후 저장하거나 게시한다. 같은 요청 키와 같은 본문의 재전송은 기존 성공 응답을 반환하며 버전을 다시 올리지 않는다.

다른 화면에서 먼저 저장했다면 오래된 수정·게시 요청은 `409 DRAFT_VERSION_CONFLICT`다. 편집 화면은 입력을 유지하고 **수정 취소하고 최신 초안 보기**를 제공한다. 이 버튼으로 입력을 버리고 최신본을 명시적으로 불러온다. 서버가 바뀐 내용을 자동으로 덮어쓰지 않는다.

한 번 게시한 초안은 전체 수정이 잠긴다. 게시 문항의 문제·보기·정답·풀이는 게시 당시 값으로 고정하며 학생 제출 채점, 개인 오답과 교수 레포트가 같은 값을 사용한다. 게시 전 학생에게 제공하는 PublicQuiz에는 정답·풀이·출처를 포함하지 않는다. 학생·다른 강의 교수는 초안을 수정할 수 없다.

## 검증

자동 검사는 문서·YouTube 수정과 출처 보존, 저장·재시작, 수정한 정답의 채점·오답·레포트, 권한, 입력 오류, 중복 요청, 오래된 버전, 게시 후 수정 차단을 포함한다. 브라우저에서는 취소·저장·편집 중 이동 제한·충돌 입력 유지·명시적 최신본 조회·선택 게시·학생 오답과 390px 가로 넘침을 검사한다.

`node --import tsx scripts/verify-draft-edit.ts`는 로컬 기존 미게시 초안을 임시 DB에 복사해 수정·게시·채점·레포트를 검사한다. 실제 사용자 초안을 수정하거나 게시하지 않으며 모델 API를 호출하지 않는다. 임시 DB는 삭제하고 본문 없는 결과만 로컬 `.data/verification-draft-edit`에 남긴다. 실제 결과와 범위는 [검증 기록](verification.md)을 따른다.
