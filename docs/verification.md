# 검증 기록

2026-10-21, 로컬 개발 환경에서 수행했다. GitHub Actions 결과와 구분한다.

## 통과한 검사

- `npm run typecheck`: 백엔드·프런트엔드 TypeScript 검사 통과.
- `npm test`: 서버 17개와 Python 문서 추출 2개 검사 통과.
- `npm run build`: Express 실행 파일과 Vite 정적 파일 생성 통과.
- `scripts/check_contracts.py`: OpenAPI·Worker 샘플·학생 응답 정답 비노출·Figma SVG 체크섬 통과.
- `npm audit --audit-level=high`: 확인 시점 알려진 취약점 0개.
- 실제 60페이지 한국어 강의 PDF에서 2~15페이지 텍스트·원래 페이지 번호 추출 확인.
- 실제 같은 PDF로 퀴즈 Playwright 브라우저 검사 통과: 교수 업로드·3문항 초안·2문항 선택 게시·학생 제출·오답·새로고침·다른 학생 격리·390px 모바일 가로 넘침 검사. **이 검사에서 생성 응답은 테스트 대역이다.**
- 기존 ChatGPT 로그인으로 Codex CLI를 호출해 실제 강의 PDF에서 객관식 문제·정답·풀이·페이지 출처 1개 생성 확인. 결과의 형식과 출처 범위를 검사했다.

## 서버 검사 범위

선택 범위 준수, 일부 문항만 게시, 제출 전 정답·풀이 비노출, 비공개 원본·교수 초안 접근 거부, 학생·강의 간 접근 제어, 개인 결과 격리, 서버 채점, 같은 제출 키 재전송, 1회 제출 제한, 로그아웃, 외부 Origin 거부, 재시작 후 결과 보존, 자료 범위 초과, 키 누락, 모델 오류, 범위 밖 출처 거부, 테스트 대역으로 50문항 배치 생성.

## 실제 50문항 검증

사용자가 제공한 60페이지 한국어 강의 PDF의 **2~60페이지**로 실제 Codex를 호출했다. 테스트 대역을 사용하지 않았다.

- 생성: **50문항**, 보기·정답·풀이·페이지 출처 검증 통과.
- 교수 게시: 생성한 문항 중 **5개 선택 게시**.
- 학생 조회: 게시된 **5문항만 반환**, 정답·풀이 비노출 확인.
- 서버 채점: 검증용 답안을 제출해 **1개 정답·4개 오답**, 기대값과 일치.
- 학생 결과: 오답 4개와 정답·풀이 확인.

검증은 `node --import tsx scripts/verify-live-flow.ts <로컬 자료 경로> 50 2 60`으로 수행했다. 원본 PDF와 생성 결과는 로컬 `.data/`에만 남겼다. 생성 문항·원본 강의 PDF·로그인 정보는 저장소에 올리지 않았다. 50개 문항 전체의 내용상 정확성·난이도를 교수 검토로 평가한 결과는 아니다.

## 남은 검증

OpenAI API는 키 인증·모델 접근을 확인했지만 실제 생성은 잔액 부족(`credit_balance_exhausted`)으로 완료하지 못했다. Supabase·JWT·Storage·RLS, 실제 Jev 외부 판단, 레포트, 실제 서비스 배포는 아직 검증하지 않았다. 모델 출력 구조·출처 검증은 내용상 정답을 보증하지 않는다.

## Q&A 검증

같은 날 Q&A를 추가하고 TypeScript·빌드·계약 검사를 다시 수행했다. 서버 검사는 기존 5개와 Q&A 12개로 총 17개다. Python 추출 2개, Playwright 브라우저 2개(퀴즈·Q&A)가 통과했다.

- 서버: 근거 있는 답변·출처, 보완 질문 1회, 학생 답변 후 재검색·재판단, 여전히 모호하거나 근거가 부족한 질문의 승격, 교수 답변, 중복 요청·오래된 버전 거부, 다른 학생·강의 격리, 교수만 판단 기록 조회.
- 실패: Jev 키 누락은 오류이며 승격하지 않음, 생성 실패 뒤 재시도해도 질문 횟수 중복 없음, 불확실한 판단·출처 없는 답변의 승격, 대화·추가 질문 횟수의 재시작 보존.
- 검색: 다른 강의·주차·미완료 자료와 교수 선택 범위 밖 페이지를 제외한다. 원본 비공개 자료도 허용된 AI 처리에는 사용한다.
- SDK: 실제 `@typesafe-ai/sdk`에 HTTP 테스트 대역을 주입하여 버전·두 choice·확률 파싱과 인증 실패 처리를 확인했다. 외부 Jev 호출은 아니다.
- 브라우저: 학생의 모호한 질문, 추가 질문 1회, 학생 보완, 교수 승격, 교수 답변, 학생의 완료 확인, 다른 학생 격리와 390px 가로 넘침 검사를 통과했다. 이 검사의 Jev 판단·생성 응답은 모두 명시적인 테스트 대역이다.

실제 강의 PDF를 대상으로 로컬 검색 결과 6개를 전달하여 **실제 Codex CLI**로 381자 답변과 27자 보완 질문 문장을 생성했다. 답변 출처는 물리 페이지 7·8이었고 검색 근거와 일치했다. 이 검증은 Jev 판단을 호출하지 않고 생성 모듈을 직접 확인했다. 원본 문서와 생성한 본문은 커밋하지 않았다.

로컬 실행 서버의 `/api/health`는 `contract_version=0.3.0-qa.1`, `provider=codex`, `jev_configured=false`, `qa_configured=false`를 반환했다. 실제 TypeSafe 키가 없어 전체 실제 Q&A 모델 연결과 한국어 판단 정확도·임계값은 검증하지 못했다. `jev-1.13.0`과 0.75 임계값을 검증 완료값으로 해석하지 않는다.
